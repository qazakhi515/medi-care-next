## Hospital Card Design System

Use this design style for all hospital cards.

Design:

- Premium healthcare appearance
- Large hospital cover image
- Rounded corners (24px)
- Soft shadow
- Clean white background
- Brand color accents
- Modern spacing

Content:

- Hospital image
- Hospital name
- Address
- Available departments count
- Doctor count
- Rating if available
- View Hospital button

Layout:
[ Hospital Image ]
[ Hospital Name ]
[ Address ]
[ Departments | Doctors ]
[ View Hospital ]

Effects:

- Image zoom on hover
- Card elevation on hover
- Framer Motion fade-up animation
- Smooth transitions

Style Goal:
Modern healthcare marketplace.
Similar quality to premium healthcare websites and Dribbble medical UI examples.

Requirements:

- Reuse this design across all hospital listings.
- Keep consistent spacing and typography.
- Do not create different hospital card styles.
