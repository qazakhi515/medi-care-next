## Doctor Card Design System

Use this design style for all doctor cards across the project.

Design:

- Premium healthcare appearance
- Rounded corners (20-24px)
- Soft shadow
- Large doctor image (top section)
- Floating specialty icon
- White card background
- Brand color accents only
- Clean spacing
- Mobile-first layout

Content:

- Doctor photo
- Doctor name
- Specialty
- Years of experience
- Patient count if available
- View Profile button

Effects:

- Smooth hover elevation
- Slight image zoom on hover
- Framer Motion fade-up animation on load
- No heavy animations

Card Layout:
[ Doctor Image ]
[ Specialty Badge ]
[ Doctor Name ]
[ Specialty ]
[ Experience | Patients ]
[ View Profile Button ]

Style Goal:
Modern premium healthcare website similar to top Dribbble healthcare UI examples.

Requirements:

- Reuse this design everywhere.
- Keep visual consistency.
- Do not create alternative card styles unless explicitly requested.
